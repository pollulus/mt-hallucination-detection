# mt-hallucination-detection

Разработка магистерской диссертации на **тему** "Безэталонное выявление галлюцинаций в документном англо-русском переводе финансово-аналитических текстов, выполненном большими языковыми моделями".

**Цель работы**: оценить эффективность безэталонных методов выявления галлюцинаций для предварительного отбора сегментов, требующих постредактирования, в переводах текстов экономической аналитики.
